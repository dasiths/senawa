# Workflow State Machine Redesign

The redesign research moved into focused documents under
[research/](research/README.md). This path remains as a compatibility pointer for
earlier links and discussion.

Start with [Product Vision and Design
Principles](research/01-product-vision-and-principles.md), then follow the
[research reading order](research/README.md#reading-order).

The focused set owns:

* Product scope and authority
* Canonical workflow and domain semantics
* Completion, gates, escalation, and closure
* Cross-agent context and parallel execution
* Supervisor, embedded runtime, HTTP, and remote control plane
* Current-system divergence and falsifiable migration slices

This page is not a separate design authority. Do not add new redesign contracts
here.
