# Senawa Design

Senawa is in an alpha implementation reset. There is no authoritative current
architecture guide yet.

The proposed product and architecture are documented in [Redesign
Research](wip/research/README.md). The autonomous implementation sequence is in
the [Comprehensive Alpha Implementation
Plan](wip/research/07-comprehensive-implementation-plan.md), and decisions and
deviations are recorded in the [Redesign Implementation
Log](wip/redesign-implementation-log.md).

The numbered files in this directory are retired compatibility pages retained
for historical decision links. They do not describe the reset implementation.

Measured historical behavior remains in [Probe Findings](wip/probe-findings.md),
and rejected rationale remains in [Roads Not Taken](wip/roads-not-taken.md).
